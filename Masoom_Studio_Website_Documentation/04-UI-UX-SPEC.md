# UI/UX Specification

## Home
Header/logo → cinematic hero and enquiry CTA → short approved brand statement → selected portfolio → confirmed services → film showcase → process (if verified) → enquiry CTA → contact/location → social links → footer.

## Pages
About contains approved story and approach. Weddings and Pre-Wedding contain relevant real work. Films uses posters and click-to-play. Portfolio may have category filters only if enough work exists. Contact includes verified phone/email/WhatsApp, map and short form. Privacy describes actual data handling.

## Enquiry journey
Visitor selects service and submits event date, location and contact details. Display a clear acknowledgement that this is an enquiry, not a confirmed booking. No payments or date reservations unless a real system is approved and implemented.

## Gallery
Use approved work only. Descriptive alt text; keyboard-operable lightbox with Escape and focus management. Do not load all large videos/images on initial render.

## Responsive/accessibility
No overflow at 320px. Keyboard-accessible navigation, visible focus, WCAG AA contrast, readable labels/errors, touch-friendly controls, semantic headings and `prefers-reduced-motion` support.
