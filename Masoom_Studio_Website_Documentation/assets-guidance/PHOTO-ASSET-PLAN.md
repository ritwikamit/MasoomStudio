# Photo and Film Asset Plan

Request the original logo (SVG/AI/PDF if available), best wide hero image/video, approved wedding portfolio, pre-wedding samples, function coverage, film posters/official links, team photo if desired, and approved testimonials.

Suggested folders: `public/images/masoom-studio/hero/`, `weddings/`, `pre-wedding/`, `functions/`, `team/`, `social-share/`. Keep video posters separate and stream from an authorized host when practical.

Use only owner-supplied or permission-cleared media. Do not scrape or hotlink directory/social photos. Confirm permission for identifiable clients and children. Preserve originals, create WebP/AVIF derivatives, use accurate alt text, and avoid loading every video on the first page render.
