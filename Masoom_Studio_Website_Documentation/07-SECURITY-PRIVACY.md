# Security & Privacy

- Validate enquiry submissions on the server and restrict field lengths.
- Apply rate limiting and anti-spam protection.
- Escape user input; do not inject raw HTML.
- Deliver enquiries only to an owner-approved destination.
- Do not store leads unless needed and approved.
- Keep credentials in server-side environment variables, never in source code or Git.
- Audit dependencies and scan for secrets.
- Use HTTPS and appropriate security headers.
- Clearly identify third-party embeds and links.
- The privacy notice must accurately describe forms, analytics, video embeds, map embeds and any retention of enquiries.
